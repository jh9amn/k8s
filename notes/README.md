# 🚀 Kubernetes Cheat Sheet

> A complete Kubernetes cheat sheet built from **beginner to advanced**, covering daily commands, concepts, debugging, production tips, monitoring, Helm, CRDs, OpenShift, and interview preparation.

---

## 📖 About

This repository is a practical Kubernetes reference designed for:

- 📚 Learning Kubernetes from scratch
- 🔁 Quick revision before interviews
- 💼 Daily DevOps/Kubernetes tasks
- 🚀 Production troubleshooting
- 🎯 CKA/CKAD preparation
- 💻 Real-world command reference

Instead of listing commands without context, each section explains:

- What the command does
- When to use it
- Common options
- Real examples
- Common mistakes
- Best practices
